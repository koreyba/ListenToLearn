## Implemented: D1 Projection and APIs

- `scripts/generate-connected-speech-migration.mjs` deterministically converts the typed cards into phrase, analysis, and mechanism upserts. Its `--write` mode replaces only the marked generated section of the pending migration.
- Importing the canonical catalog performs runtime validation of the exact 140/18/22/100 structure before generation; invalid formats, counts, ranks, mechanisms, analysis, or brackets fail before SQL is written.
- `drizzle/0013_kind_trauma.sql` creates the optional-analysis tables and projects 140 active cards with 230 mechanism relations. It never deletes phrases, progress, examples, or video origins and never updates phrase status.
- Existing preset upserts preserve their `updated_at` value so applying the catalog does not reorder a learner's material as a side effect.
- `lib/catalog/catalog-api.ts` groups ordered D1 join rows into one card/phrase response. Active catalog rows have non-null analysis; custom and retired legacy rows have `analysis: null`.
- `app/api/catalog/route.ts` is a public, read-only, cacheable D1 projection with formats and mechanism metadata and no account state.
- `app/api/phrases/route.ts` joins optional analysis for account reads. Custom creation rejects supplied catalog metadata, stores no fabricated grouping, and returns `analysis: null`.
- The previously failing TypeScript/Node import contract is resolved by explicitly enabling `allowImportingTsExtensions` for the no-emit TypeScript configuration, preserving Node's direct `.ts` test imports.

## Implemented: Library, Practice, and Compatibility

- `/library` owns catalog discovery. The independently delivered landing page remains at `/`, and React/static trainer navigation links Library directly to `/library`.
- Library exposes the three practice formats, all six named mechanisms with plain-language hints, one-mechanism filtering, search, recommended/alphabetical ordering, analyzed cards, and Add/Undo feedback.
- `lib/catalog/guest-catalog.ts` merges the public catalog with stable-ID guest statuses, retains unmatched legacy presets only when already non-`pick`, and maps guest custom phrases to `analysis: null`.
- Practice still owns To Learn, Learning Now, Learned, explicit trainer entry, and removal. Analysis UI is rendered only for an analyzed card; custom/legacy cards show no fake IPA, grouping, or mechanism metadata.
- The custom phrase form remains available in guest/account mode and requires text only. An account text match reuses the existing phrase without replacing its catalog analysis in React state.
- Worker/guest routing exposes `/library` and GET/HEAD `/api/catalog` without widening account mutation access.
