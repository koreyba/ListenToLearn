# Library Direct Practice Monitoring

After merge, verify that Library `Practice` opens the selected phrase, browser Back returns to the same Library context, and the phrase remains unsaved until `Add to Learn` is explicitly selected. On each Practice tab, verify that `Add your own` creates the phrase in `To Learn` and switches to that tab.
